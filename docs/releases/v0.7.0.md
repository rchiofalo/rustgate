## What's New

### Post-Quantum Cryptography (Phase 1)
- **`post-quantum` feature flag** — hybrid X25519MLKEM768 key exchange via aws-lc-rs. PQ-capable clients negotiate hybrid PQ+classical key exchange; others fall back to X25519 transparently (#496, #498)
- **`--kx-groups` CLI flag** — runtime control over TLS key exchange group preference order. Supports X25519MLKEM768, SECP256R1MLKEM768, MLKEM768, MLKEM1024, X25519, secp256r1, secp384r1 (#497)
- **PQ integration tests + CI job** — full test suite and dedicated CI job for post-quantum builds (#499)
- **KX group logging** — negotiated key exchange group logged for every TLS connection (transport, federation, WebSocket)

### Certificate Revocation
- **`POST /api/revoke`** — revoke certificates by serial, persisted to JSON revocation database (#411)
- **`GET /api/crl`** — auto-generated CRLs signed by enrollment CA
- **`GET /api/revoked`** — list all revoked entries

### Security & Reliability
- **HA fencing tokens** — monotonic fencing tokens prevent split-brain in multi-pod federation (#458)
- **Data package signature verification** — ECDSA P-256 and RSA-PSS signature verification on uploads (#423)
- **Session circuit breaker** — disconnect slow clients after consecutive send failures (#420)
- **Per-group access control** — JSON-based ACL for send/receive permissions per group (#416, #417)
- **WebSocket rate limiting** — per-connection frame-rate and byte-rate limits (#422)

### Infrastructure
- **NATS JetStream pull consumer** — real backpressure with explicit ack (#415)
- **JetStream resumption checkpoints** — restart from last processed sequence (#413)
- **Federation replay buffer** — bounded per-peer ring buffer for reconnection replay (#409)

### Documentation
- Crypto agility strategy, REST API reference, operational guides, troubleshooting, and runbooks
