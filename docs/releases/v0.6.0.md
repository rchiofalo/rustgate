## What's Changed

### ⚠️ Breaking Changes

- **Standardized environment variable prefixes** — all environment variables now use the `RUSTGATE_` prefix for consistency and to avoid collisions with other services. `NATS_*` → `RUSTGATE_NATS_*`, `FEDERATION_*` → `RUSTGATE_FEDERATION_*`, `ENROLLMENT_*` → `RUSTGATE_ENROLLMENT_*`, `METRICS_BIND` → `RUSTGATE_METRICS_BIND`, `WEBSOCKET_BIND` → `RUSTGATE_WEBSOCKET_BIND`, `DATA_PACKAGE_DIR` → `RUSTGATE_DATA_PACKAGE_DIR`. `OTEL_*` vars unchanged (OpenTelemetry standard). Update deployment configs, Helm values, and shell scripts. (#392)
- **WebSocket codec migration** — WebSocket transport now uses the unified `Codec` trait (`Arc<dyn Codec>`) instead of the legacy `WsEncoding` enum and `MessageEncoder` trait. `WsServerConfig.encoding` field replaced by `WsServerConfig.codec`. (#391)

### Added

- **Pluggable codec architecture** — unified `Codec` trait replaces separate `Framing`/`Encoding` dispatch. Each wire protocol implements a single trait covering framing, payload decode/encode, and protocol detection. (#184)
- **Server certificate hot-reload** — `--cert-reload-interval` enables periodic polling with atomic swap for zero-downtime certificate rotation. (#291)
- **OpenTelemetry distributed tracing** — `otel` feature flag adds OTLP trace export via `--otel-endpoint`. Works with Jaeger, Grafana Tempo, and any OTLP-compatible backend. (#281)
- **Dynamic TLS config refresh** — trust store changes take effect on the next TLS handshake without server restart. (#192)
- **Circuit breaker metrics and audit events** — Prometheus counters for circuit breaker trips/recoveries and structured audit events. (#289)
- **External Secrets Operator support** — ExternalSecret templates for NATS, enrollment, and federation secrets. (#275)
- **Anti-replay detection** — sliding-window filter drops duplicate `(uid, time)` pairs within a configurable window. (#284)
- **FIPS-enabled release binaries** — FIPS 140-3 binaries (aws-lc-rs) for x86_64-musl and aarch64-gnu alongside standard binaries. (#366)
- **Comprehensive documentation** — STRIDE threat model, graceful degradation policy, post-quantum TLS roadmap, expanded NIST 800-53 control mapping. (#261, #256, #263, #279, #280, #290, #295, #308, #311)

### Fixed

- **Timestamp parsing panics** — prevent panics when CoT and protobuf parsers encounter malformed timestamps with out-of-range values. (#371)

### Security

- **Quarterly advisory review** — upgraded async-nats 0.46→0.47, resolving RUSTSEC-2025-0134 and RUSTSEC-2026-0049. Zero known vulnerabilities. (#239)
