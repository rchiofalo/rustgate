## What's Changed

### Federation (feature-gated: `federation`)

- **V1 protocol** — length-prefixed XML over mTLS with CoT heartbeat monitoring and automatic reconnection with exponential backoff
- **V2 protocol** — gRPC FederatedChannel service over mTLS with 5-stream handshake, group exchange, health checks, and bidirectional event streaming
- **Provenance-based loop detection** — messages carry a server chain and hop counter; dropped when a loop is detected or the configurable hop limit (default 10) is exceeded
- **Dynamic CA trust store** — add/remove trusted CAs at runtime without restart
- **Persistent peer storage** — JSON file backend (single-pod) or NATS KV backend (multi-pod clusters)
- **HA mode** — distributed peer ownership via NATS KV atomic claims with automatic adoption of orphaned peers
- **REST API** — peer CRUD, certificate management, connection status, and statistics under `/api/federation/`
- **Prometheus metrics** — connection gauge, message/error/heartbeat counters
- **CLI flags** — `--federation-v1-bind`, `--federation-id`, `--federation-peers-file`, `--federation-skip-hostname-verify`, `--federation-max-hops`, `--federation-store-path` with corresponding `FEDERATION_*` env vars

### New Features

- **Audit logging** — structured event logging for connection lifecycle and federation events
- **Marti contact API** — `/Marti/api/contacts/all` and `/Marti/api/clientEndPoints` for TAK client contact discovery
- **Data package support** — upload, download, and keyword search via `/Marti/sync/` endpoints
- **Directional group routing** — group-aware message filtering for federation peers
- **Fuzz targets** — cargo-fuzz targets for XML stream codec, CoT parser, TAK frame codec, length-prefixed codec, and federation converter
- **Criterion benchmarks** — throughput benchmarks for CoT parsing, codec encode/decode, and federation XML conversion
- **Container security scanning** — Trivy vulnerability scanning with SARIF upload in release workflow
- **Binary release artifacts** — cross-compiled static binaries for x86_64 and aarch64 linux-musl

### CI/CD

- Split single sequential CI job into 6 parallel jobs (fmt, clippy, test matrix, audit, helm, docker)
- 12 feature combinations now run concurrently via GitHub Actions matrix strategy
- `main` requires all 17 CI status checks to pass before merge

### Helm Chart

- Federation support — `federation.enabled` toggle, peer config via Secret or values, federation port in Service and NetworkPolicy

### Testing

- **701 tests** — up from 198 in v0.1.0, covering federation config, provenance, heartbeat, store, V1/V2 protocols, gRPC service, trust store, HA claims, REST API, metrics, audit logging, Marti APIs, and data packages
