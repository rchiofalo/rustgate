# Archived release notes

rustgate's GitHub Releases for v0.1.0 through v0.9.0 were removed on
2026-10-14, ahead of the public launch under AGPL-3.0-only. Those binaries
predated many security fixes that `CHANGELOG.md` documents in detail, and
they shipped without license text. The **git tags were kept**, so every
version's source is still available.

[`CHANGELOG.md`](../../CHANGELOG.md) remains the canonical changelog. The
original release notes are preserved here verbatim, because several
contain narrative and PR lists that were never copied into the changelog.
