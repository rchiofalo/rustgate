# rustgate v0.8.0

> **Archived release notes.** Copied verbatim from the GitHub Release for tag
> `v0.8.0` (published 2026-04-12) before GitHub Releases v0.1.0–v0.9.0 were removed
> on 2026-10-14, ahead of rustgate's public AGPL-3.0-only launch. The git tag
> `v0.8.0` is retained, so the source for this version is still available.
> The canonical changelog is [`CHANGELOG.md`](../../CHANGELOG.md); these notes
> are kept for the release narrative and PR lists they contain.
>
> The release shipped 14 asset(s): `multiple.intoto.jsonl`, `rustgate-fips-v0.8.0-aarch64-unknown-linux-gnu.tar.gz`, `rustgate-fips-v0.8.0-aarch64-unknown-linux-gnu.tar.gz.sha256`, `rustgate-fips-v0.8.0-aarch64-unknown-linux-gnu.tar.gz.sigstore.json`, `rustgate-fips-v0.8.0-x86_64-unknown-linux-musl.tar.gz`, `rustgate-fips-v0.8.0-x86_64-unknown-linux-musl.tar.gz.sha256`, `rustgate-fips-v0.8.0-x86_64-unknown-linux-musl.tar.gz.sigstore.json`, `rustgate-v0.8.0-aarch64-unknown-linux-musl.tar.gz`, `rustgate-v0.8.0-aarch64-unknown-linux-musl.tar.gz.sha256`, `rustgate-v0.8.0-aarch64-unknown-linux-musl.tar.gz.sigstore.json`, `rustgate-v0.8.0-x86_64-unknown-linux-musl.tar.gz`, `rustgate-v0.8.0-x86_64-unknown-linux-musl.tar.gz.sha256`, `rustgate-v0.8.0-x86_64-unknown-linux-musl.tar.gz.sigstore.json`, `sbom-source-v0.8.0.spdx.json`.
