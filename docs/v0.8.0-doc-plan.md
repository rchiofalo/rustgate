- Typed CoT detail extraction — `link`, `remarks`, `color`, `labels`, `usericon`, `marti` parsed into first-class structs (#696)
- Cross-field config validation at startup — TLS file existence, federation ID, rate-limit/burst checks (#697)
- Authz routing verified on federation forward and store-forward drain paths (#698)
- TAK Protocol v2 version range negotiation with backward-compatible fallback (#699)
- SA event type detection and multicast group routing with `Destination::Multicast` (#699)

- Multi-region federation — `--federation-region`, EWMA latency tracking, region/zone/priority config (#701)
- Per-tenant resource quotas — `--tenant-quota-file`, tenant from cert Organization field (#702)
- SLSA Build Level 3 provenance and Sigstore cosign signatures for releases (#703)

**Security:**
- XML injection prevention in CoT detail serialization — attribute/text escaping (#696)

**Fixed:**
- Unbounded `text_buf`/`dest_callsigns` growth in CoT parsing — capped at 64 KiB / 1000 (#696)
- Multicast duplicate delivery — dedup via `HashSet` tracking (#699)
- Multicast amplification DoS — group list capped at 32 (#699)
- Multicast authz bypass — per-group authorization enforced (#699)
- TOCTOU race in quota check — CAS loop for atomic check-and-increment (#702)
- `AtomicU32` underflow in disconnect — `fetch_update` + `saturating_sub` (#702)
- Transport layers now enforce quota rejection instead of discarding result (#702)
